### 当前 badcase 样本分析发现的两个主要问题

**问题 1：复合机构（38.2万 badcase，15.3%）**

"有限公司"身后还有"分公司""经营部""对面"等——DP 把它们摁进同一个实体。例如：

```
「湖南众福建工有限公司机电分公司」
  v1.2.2: PROVINCE→BRAND→PROVINCE→BRAND→ORG_SUFFIX→INDUSTRY→ORG_SUFFIX
  期望:   PROVINCE→BRAND→INDUSTRY→ORG_SUFFIX | TOWN→INDUSTRY→ORG_SUFFIX
```

**问题 2：过度拆分 + 类型错误（39% badcase 含 INDUSTRY→BRAND 跳变；5% VILLAGE 误标）**

- "枣庄"→VILLAGE（应是 CITY）、"石家庄"→VILLAGE（应是 CITY）
- "石家庄北"→VILLAGE（应是 CITY+ORIENTATION）

### 数据文件现况

- `data/areas/cities.csv`（343 行）——城市名总集，含 `"石家庄市"`、`"枣庄市"`
- `data/areas/streets.csv`（41353 行）——街道名
- `data/areas/villages.csv`（620574 行）——村庄名
- `data/areas/areas.csv`（2979 行）——县级区划
- `data/areas/provinces.csv`（32 行）——省级区划

### 关键架构事实

- DP 引擎在 `org/recognizer.py` 中，输入一个字符串，输出一个 `AddressResult`
- `pipeline.py` 的 `_remap_org_segments()` 已将 DP 产出的 `SegType.POI` → `SegType.ORG_SUFFIX`
- `_has_company_suffix()` 检查 segment text 是否以公司后缀结尾
- 不改 DP 引擎（红线）、不改 `core/types.py`（已解冻一次，本次不再改）

## 四、阶段 A — VILLAGE 类型错误修复

### A1. 新建 `tools/clean_loc_villages.py`

**逻辑**：

```python
#!/usr/bin/env python3
"""依据 areas/ 五级行政区划清理 LOC 词典中的错误 VILLAGE 标记"""
import os, sys, pickle, csv

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
from core.types import SegType

BASE = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
AREAS_DIR = os.path.join(BASE, "data", "areas")
DICT_DIR = os.path.join(BASE, "dicts")

def main():
    # 加载 areas 文件
    cities = set()
    with open(os.path.join(AREAS_DIR, "cities.csv"), encoding="utf-8") as f:
        for row in csv.DictReader(f):
            name = row["name"].strip().strip('"')
            for sfx in ("市", "地区", "自治州", "盟"):
                if name.endswith(sfx):
                    bare = name[:-len(sfx)]
                    if len(bare) >= 2:
                        cities.add(bare)
            cities.add(name)

    all_villages = set()
    with open(os.path.join(AREAS_DIR, "villages.csv"), encoding="utf-8") as f:
        for row in csv.DictReader(f):
            name = row["name"].strip().strip('"')
            if len(name) >= 2:
                all_villages.add(name)

    # 加载 LOC 词典
    src = os.path.join(DICT_DIR, "loc_v1.2.2.pkl")
    with open(src, "rb") as f:
        data = pickle.load(f)

    village_dict = dict(data.get(SegType.VILLAGE, {}))
    city_dict = dict(data.get(SegType.CITY, {}))
    district_dict = dict(data.get(SegType.DISTRICT, {}))
    town_dict = dict(data.get(SegType.TOWN, {}))

    removed = []
    for word, freq in list(village_dict.items()):
        # 规则1: 该词是已知城市的裸名（如"石家庄"），且在 villages.csv 中不作为独立村名出现
        if word in cities and word not in all_villages:
            del village_dict[word]
            # 将其频次转移到 CITY 词典（照顾"石家庄北"仍能正确识别为 CITY+ORIENTATION）
            city_dict[word] = max(city_dict.get(word, 0), freq)
            removed.append((word, freq, "→CITY"))

        # 规则2: 该词以城市名为前缀 + 方向词结尾（如"石家庄北"）
        for city_bare in cities:
            if word.startswith(city_bare) and len(word) == len(city_bare) + 1:
                suffix = word[-1]
                if suffix in "北南东西中上下左右前后":
                    del village_dict[word]
                    removed.append((word, freq, "→CITY+ORIENTATION"))
                    break

    data[SegType.VILLAGE] = village_dict
    data[SegType.CITY] = city_dict

    dst = os.path.join(DICT_DIR, "loc_v1.2.3.pkl")
    with open(dst, "wb") as f:
        pickle.dump(data, f)

    print(f"LOC VILLAGE cleanup: {len(removed)} entries removed")
    for word, freq, dest in removed[:20]:
        print(f"  {word} ({freq:,}) {dest}")
    print(f"Saved: {dst} ({os.path.getsize(dst)/1024/1024:.1f}MB)")
    print(f"VILLAGE entries: {len(village_dict):,}")
    print(f"CITY entries:   {len(city_dict):,}")


if __name__ == "__main__":
    main()
```

**运行**：

```bash
python tools/clean_loc_villages.py → dicts/loc_v1.2.3.pkl
```

## 五、阶段 B — 过度拆分修复

### B1. pipeline.py 新增 `_merge_over_split()`

**规则**：相邻两个段的合并文本如果存在于 `suffix_segments_sql.csv` 或 `trade_segments_sql.csv` 中，且两个段都不是行政区划段（CITY/DISTRICT/PROVINCE/TOWN/VILLAGE/COMMUNITY/ROAD），则合并。

```python
def _merge_over_split(self, segments):
    from core.csv_index import CsvIndex
    idx = CsvIndex.instance()

    ADDR_TYPES = {SegType.PROVINCE, SegType.CITY, SegType.DISTRICT,
                  SegType.TOWN, SegType.VILLAGE, SegType.COMMUNITY, SegType.ROAD}

    i = 0
    while i < len(segments) - 1:
        s1, s2 = segments[i], segments[i + 1]
        
        if s1.seg_type in ADDR_TYPES or s2.seg_type in ADDR_TYPES:
            i += 1
            continue
        
        merged = s1.text + s2.text
        
        if merged in idx.suffix or merged in idx.trade:
            if merged in idx.suffix:
                s1.seg_type = SegType.INDUSTRY if s1.seg_type == SegType.INDUSTRY else SegType.ORG_SUFFIX
            s1.text = merged
            del segments[i + 1]
            continue
        
        i += 1
    
    return segments
```

**调用位置**：`_remap_org_segments()` 之后立即调用，返回 remap 之后 merge 之后的 segments。

**不处理 POI 识别器**——POI 的过度拆分特征不同于 ORG。

## 六、阶段 C — 复合机构修复

### C1. 检测 + 重识别

**检测方法**——在已 remap 的 segments 中检查非末段的公司后缀：

```python
def _detect_compound(self, segments):
    company_suffixes = {"有限公司", "有限责任公司", "股份有限公司", "公司", "集团"}
    for i, s in enumerate(segments):
        if i == len(segments) - 1:
            continue
        if s.seg_type == SegType.ORG_SUFFIX and s.text in company_suffixes:
            return s.end
    return None
```

**重识别方法**——在检测到的切分点处切分文本，对前后半段各自重新跑 ORG 识别：

```python
def _re_split_and_recognize(self, text, split_pos):
    part1 = text[:split_pos]
    part2 = text[split_pos:]
    
    res1 = self._remap_org_segments(self.org.recognize(part1))
    res2 = self._remap_org_segments(self.org.recognize(part2))
    
    merged_segments = res1.segments + res2.segments
    for i, s in enumerate(merged_segments):
        s.start = 0 if i == 0 else merged_segments[i-1].end
        s.end = s.start + len(s.text)
    
    result = type(res1)(original=text, segments=merged_segments)
    return result
```

**调用位置**——在 `classify()` 和 `recognize()` 的 org_res 获取后立即调用：

```python
org_res = self._remap_org_segments(self.org.recognize(text))
split_pos = self._detect_compound(org_res.segments)
if split_pos is not None:
    org_res = self._re_split_and_recognize(text, split_pos)
```
