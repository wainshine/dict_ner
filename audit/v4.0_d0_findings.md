# v4.0 D0 调研报告 — 段级金标准可用性

> 2026-08-04 | 结论: 全文本金标准不存在, R2 降级为银标准学习

## 排查结果

| 候选来源 | 内容 | 是否含金标准切分 |
|---------|------|:---:|
| `data/split/org/chunk_XX.csv` | `dict,poi,idf,tag,ner,moe` | 否 — tag 是 0/1 标记列, 非切分标注 |
| `data/split/loc/chunk_XX.csv` | `dict,idf` | 否 |
| `data/split/poi/chunk_XX.csv` | `name\tfreq` | 否 |
| `data/地名A（7300w）input.txt` | GBK 纯名称, 每行一条 | 否 |
| `data/地名T（7200w）input.txt` | GBK 纯名称, 每行一条 | 否 |
| SQL 三表 (addr/trade/suffix) | 段级统计 (词,freq,com/org/loc) | **部分** — 段本身是 SQL 验证过的, 但无"名称→完整切分"的对应关系 |

## 结论

1. **全文本金标准切分不存在** — SQL 时代的切分管线不在本仓库, 只留下了段级统计表。
2. R2 (转移代价学习) 无法直接用 supervised structured learning, 降级方案:
   **银标准** = DP 输出中段全部落在 SQL 三表/areas 内的样本 (高精确自洽切分)。
3. 段级质量改用**无金标健康度指标**度量 (D1):
   - 后缀验证率: 末段 ∈ suffix_csv 的比例
   - 行业验证率: INDUSTRY 段 ∈ trade_csv 的比例
   - 地址验证率: 行政段 ∈ addr_csv/areas 的比例
   - 低频序列率: 类型序列在 seq_dist 中 freq<10 的比例 (badcase 率)
4. 下游锚点: classify val macro-F1 (词典改动后重预计算+重训, 管线已自动化)。

## R1/R2 修正设计

- **R1 错误驱动反哺**: 挖掘对象 = "末段∉suffix_csv 且分类器判 ORG" (漏后缀) / "末段含2+SQL后缀拼接" (过度合并) / "INDUSTRY段∉trade_csv 且低频" (伪行业词)
- **R2 转移代价学习**: 银标准样本集上坐标下降优化 ~40 个转移代价值, 目标 = 段级健康度 + 银标准复现率
