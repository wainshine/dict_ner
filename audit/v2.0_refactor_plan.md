## 零、已核实事实（实施依据，勿质疑）

### pkl 结构

`org_v1.1.2.pkl` / `poi_v1.1.2.pkl`：
```python
{"d1_freqs": {word: int}, "d3_freqs": {word: int}, "d4_freqs": {word: int}}
```
仅 3 键。当前规模：org d1=63750, d3=20150, d4=9597；poi d4=15384。

### split 语料格式（16 chunk 各一）

- `data/split/loc/chunk_XX.csv` — `dict,idf` 逗号分隔，总 ~3635 万行
- `data/split/org/chunk_XX.csv` — `dict,poi,idf,tag,ner,moe` 逗号分隔，总 ~1.65 亿行
- `data/split/poi/chunk_XX.csv` — `name\tfreq` **制表符分隔**，总 ~4000 万行

### 三个 SQL CSV

列结构：`d1/d3/d4,icf1,idf1,tf1,max1,com,org,loc,temp`（首行有 BOM）

com/org/loc 是**用 SQL 对 split/{loc,org,poi} 三套语料交叉统计段频**的结果，非来源于高德/腾讯 type 字段。`org_ratio>0.6` = 该段在机构名语料中出现频率高。

| CSV | 行数 | 统计 |
|-----|-----:|------|
| `addr_segments_sql.csv` | 200 万 | 37% org 主, 23% loc 主, 1.5% com 主, 38% 混合 |
| `trade_segments_sql.csv` | 4 万 | 62.6% org 主, 36.7% com 主，**当前代码完全未使用（死数据）** |
| `suffix_segments_sql.csv` | 2.4 万 | 84.6% org 主, 14.8% loc 主 |

**addr CSV 的 com/org/loc 统计特性（关键）**：短地址前缀（"深圳市""北京市"）在 org 语料中极常见（大量"深圳市XX公司"），导致 org/com 远高于 loc。已验证：

| 前缀 | com | org | loc | loc_ratio |
|------|----:|----:|----:|:---------:|
| 深圳市 | 3.44M | 230K | 7.7K | 0.00 |
| 北京市朝阳区 | 891 | 7.8K | 7.8K | 0.47 |
| 深圳市南山区 | 681 | 170K | 2.4K | 0.01 |

因此 addr_affinity 的 loc_ratio **不能作为 addr_score 的基础分**，仅作 boost。

### org/recognizer.py 输出

d4→`SegType.POI`，d3→`SegType.INDUSTRY`，UNKNOWN→`SegType.BRAND`。无独立 to_dict()，用 `core/types.py:125` 的 `AddressResult.to_dict()` 共享方法，输出 `s.seg_type.value` 原样无重映射。`poi_type` 在 `org/recognizer.py:474,498` 无条件调 `classify_suffix` 赋值。

### classify_suffix

定义在 `loc/importer.py:27`，被 ORG 和 LOC 共用，查 `POI_SUFFIX_MAP`（来自 `dicts/poi_suffix_category.csv`，131 行）。

### pipeline.recognize() 输出

`{"text", "loc": to_dict(), "org": to_dict(), "poi": to_dict()|None}`，无顶层 category。POI 仅当 `_has_company_suffix(org_res)` 为真时跳过。

### suffix_affinity 无法区分 ORG/POI（关键发现）

suffix_csv 中"国贸店"(应为 POI) 和"理发店"(应为 ORG) 的 org_ratio 都是 1.00。亲和度只告诉我们"这不是地址"，但分不出是机构还是店铺分支。需双硬规则 + 双负推断解决。

## 一、概念定义（最高优先级）

### 分类体系：4 类

| 类别 | 定义 | 判别特征 |
|------|------|---------|
| **ADDR** | 行政区划及组合、山川河流等自然地理、道路交通、街道小区门牌、方位词 | LOC 识别器全部输出范围 |
| **ORG** | 有组织机构代码的法人实体（公司/政府/事业单位/医院/学校/银行总部） | 公司后缀(公司/有限/集团)、政府后缀(委/局/办)、机构后缀(人民医院/学校) |
| **POI** | 连锁分支机构/店铺/服务点/公共设施——有地理属性的点位 | 店铺后缀+地理信号(店/超市/餐厅)、设施后缀免检(停车场/公厕/收费站) |
| **UNKNOWN** | 无法判断 | 评分低于阈值 T |

### ORG vs POI 分界

- "华为技术有限公司" → ORG（公司法人）
- "广东省卫健委" → ORG（政府机构）
- "XX人民医院" → ORG（事业单位，无店铺后缀）
- "星巴克咖啡望京店" → POI（连锁分支 + 地理属性）
- "XX停车场" → POI（公共设施，免检）
- "理发店" → ORG（行业词 + 店，无地理属性）
- "北京市朝阳区" → ADDR
- "西湖" → ADDR

**调用**：

### A4. v1.2.3 基线

块 A 执行时 `classify()` 尚不存在。用临时简易分类器：
```python
def _baseline_classify(pipe, text):
    org_res = pipe.org.recognize(text)
    if pipe._has_company_suffix(org_res):
        return "ORG"
    loc_res = pipe.loc.recognize(text)
    geo_cov = sum(len(s.text) for s in loc_res.segments
                  if s.seg_type in _GEO_SEG_TYPES) / max(1, len(text))
    if geo_cov > 0.6:
        return "ADDR"
    poi_res = pipe.poi.recognize(text)
    if poi_res.segments:
        return "POI"
    return "UNKNOWN"
```

## 五、块 B — classify() 实现

### B1. `core/csv_index.py`（新增）

```python
"""CSV 亲和度索引 — 从手工切分的 SQL CSV 构建运行时评分信号

com/org/loc 列是用 SQL 对 split/{loc,org,poi} 三套语料交叉统计段频的结果，
非来源于高德/腾讯 type 字段。org_ratio>0.6 = 该段在机构名语料中出现频率高。
"""
import csv, os
from typing import Optional

BASE_DIR = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
DATA_DIR = os.path.join(BASE_DIR, "data")

SAFE_SINGLE = {"厂", "店", "站", "园", "局", "院"}


class AffinityEntry:
    __slots__ = ("word", "org", "loc", "com", "org_ratio", "loc_ratio")

    def __init__(self, word, org, loc, com):
        self.word = word
        self.org = org
        self.loc = loc
        self.com = com
        total = org + loc + com
        self.org_ratio = org / total if total > 0 else 0.0
        self.loc_ratio = loc / total if total > 0 else 0.0


def _load_affinity_csv(path, key_col):
    result = {}
    if not os.path.exists(path):
        return result
    with open(path, encoding="utf-8-sig") as f:
        for row in csv.DictReader(f):
            word = row[key_col].strip()
            if not word or len(word) < 1:
                continue
            if len(word) == 1 and word not in SAFE_SINGLE:
                continue
            try:
                com = int(row.get("com", 0) or 0)
                org = int(row.get("org", 0) or 0)
                loc = int(row.get("loc", 0) or 0)
            except (ValueError, KeyError):
                continue
            if org == 0 and loc == 0 and com == 0:
                continue
            result[word] = AffinityEntry(word, org, loc, com)
    return result


class CsvIndex:
    """三 CSV 亲和度索引，单例懒加载。"""
    _instance = None

    def __init__(self):
        self._suffix = None
        self._trade = None
        self._addr = None

    @classmethod
    def instance(cls):
        if cls._instance is None:
            cls._instance = cls()
        return cls._instance

    @property
    def suffix(self):
        if self._suffix is None:
            self._suffix = _load_affinity_csv(
                os.path.join(DATA_DIR, "suffix_segments_sql.csv"), "d4")
        return self._suffix

    @property
    def trade(self):
        if self._trade is None:
            self._trade = _load_affinity_csv(
                os.path.join(DATA_DIR, "trade_segments_sql.csv"), "d3")
        return self._trade

    @property
    def addr(self):
        if self._addr is None:
            a = _load_affinity_csv(
                os.path.join(DATA_DIR, "addr_segments_sql.csv"), "d1")
            # 200 万行仅保留有明确主导(2x以上)的条目以省内存
            self._addr = {w: e for w, e in a.items()
                          if e.org >= 2 * max(e.loc, e.com)
                          or e.loc >= 2 * max(e.org, e.com)}
        return self._addr

    def lookup_suffix(self, text):
        """找 text 末尾最长的 d4 后缀匹配。"""
        if not text or not self.suffix:
            return None
        for end in range(len(text), 0, -1):
            for start in range(0, end):
                w = text[start:end]
                if w in self.suffix:
                    return self.suffix[w]
        return None

    def lookup_trade(self, text):
        """找 text 中含的 d3 行业段（最长匹配）。"""
        if not text or not self.trade:
            return None
        best = None
        for w, e in self.trade.items():
            if w in text and (best is None or len(w) > len(best.word)):
                best = e
        return best

    def lookup_addr(self, text):
        """找 text 开头最长的 d1 前缀匹配。"""
        if not text or not self.addr:
            return None
        for end in range(len(text), 0, -1):
            w = text[:end]
            if w in self.addr:
                return self.addr[w]
        return None
```

内存：suffix 2.4 万 + trade 4 万 + addr 过滤后 ~80 万 ≈ 70MB。

注意：addr_affinity 的 loc_ratio 因短地址前缀在 org 语料高频而偏低（"深圳市" loc_ratio=0.00），因此**不能作为 addr_score 基础分**，仅作 boost（见 B3 修正）。

```python
GOV_SEED = os.path.join(DATA_DIR, "gov_suffix_seed.csv")
GOV_SEED_FREQ = 50000


def merge_gov_seed(pruned):
    if not os.path.exists(GOV_SEED):
        return pruned, 0
    d4 = dict(pruned["d4_freqs"])
    injected = 0
    boosted = 0
    with open(GOV_SEED, encoding="utf-8-sig") as f:
        for row in csv_mod.DictReader(f):

            if not sfx or len(sfx) < 2:

            d4[sfx] = new_freq
    pruned["d4_freqs"] = d4
    return pruned, injected, boosted


pruned, gov_injected, gov_boosted = merge_gov_seed(pruned)
print(f"Gov suffix seed: +{gov_injected} new, boosted {gov_boosted} existing "
      f"(total d4: {len(pruned['d4_freqs']):,})", flush=True)
```

```python
def classify(self, text: str) -> dict:
    text = text.strip()
    if not text:
        return {"text": "", "category": "UNKNOWN", "confidence": 1.0,
                "best": None, "all": None}
    loc_res = self.loc.recognize(text)
    org_res = self.org.recognize(text)
    has_comp = self._has_company_suffix(org_res)
    poi_res = None if has_comp else self.poi.recognize(text)
    feats = self._extract_features(text, loc_res, org_res, poi_res, has_comp)
    scores = self._score(feats)
    category, confidence = self._decide(feats, scores)
    best = self._select_best(category, loc_res, org_res, poi_res)
    return {
        "text": text,
        "category": category,
        "confidence": round(confidence, 4),
        "best": best,
        "all": {
            "loc": loc_res.to_dict(),
            "org": org_res.to_dict(),
            "poi": poi_res.to_dict() if poi_res else None,
        },
    }


def classify_batch(self, texts) -> list:
    return [self.classify(t) for t in texts]
```

```python
def _extract_features(self, text, loc_res, org_res, poi_res, has_comp):
    from core.csv_index import CsvIndex
    idx = CsvIndex.instance()

    org_segs = org_res.segments
    org_last = org_segs[-1] if org_segs else None
    d4_suffix = org_last.text if (org_last and org_last.seg_type == SegType.POI) else None
    has_gov = False
    if org_last and d4_suffix:
        has_gov = any(org_last.text.endswith(g) for g in GOV_SUFFIXES)
    has_industry = any(s.seg_type == SegType.INDUSTRY for s in org_segs)

    poi_segs = poi_res.segments if poi_res else []
    poi_last = poi_segs[-1] if poi_segs else None
    poi_d4 = poi_last.text if (poi_last and poi_last.seg_type == SegType.POI) else None

    n = max(1, len(text))
    admin_cov = sum(len(s.text) for s in loc_res.segments
                    if s.seg_type in _ADDR_TYPES) / n
    location_cov = sum(len(s.text) for s in loc_res.segments
                       if s.seg_type in (SegType.LOCATION, SegType.ORIENTATION)) / n
    geo_cov = admin_cov + location_cov

    d1_prefix = ""
    for s in loc_res.segments:
        if s.seg_type in _ADDR_TYPES:
            d1_prefix += s.text
        else:
            break
    d1_prefix = d1_prefix or None

    d3_text = "".join(s.text for s in org_segs
                      if s.seg_type == SegType.INDUSTRY) or None

    sfx_aff = idx.lookup_suffix(d4_suffix) if d4_suffix else None
    trd_aff = idx.lookup_trade(d3_text) if d3_text else None
    addr_aff = idx.lookup_addr(d1_prefix) if d1_prefix else None
    poi_sfx_aff = idx.lookup_suffix(poi_d4) if poi_d4 else None

    has_geo = any(s.seg_type in _GEO_SEG_TYPES for s in loc_res.segments)

    return {
        "n": n, "has_comp": has_comp, "has_gov": has_gov,
        "d4_suffix": d4_suffix, "d3_text": d3_text, "d1_prefix": d1_prefix,
        "poi_d4": poi_d4, "has_industry": has_industry, "has_geo": has_geo,
        "org_has_poi_terminal": org_last is not None and org_last.seg_type == SegType.POI,
        "poi_has_poi_terminal": poi_last is not None and poi_last.seg_type == SegType.POI,
        "admin_cov": admin_cov, "geo_cov": geo_cov,
        "sfx_aff": sfx_aff, "trd_aff": trd_aff,
        "addr_aff": addr_aff, "poi_sfx_aff": poi_sfx_aff,
    }
```

#### _score

```python
def _score(self, f):
    # --- ORG ---
    sfx_org_r = f["sfx_aff"].org_ratio if f["sfx_aff"] else 0.0
    trd_org_r = f["trd_aff"].org_ratio if f["trd_aff"] else 0.0
    if f["has_comp"] or f["has_gov"]:
        org_score = 0.90 + 0.08 * (f["has_industry"] or trd_org_r > 0.5)
    elif sfx_org_r > 0.6:
        org_score = sfx_org_r * 0.80
    else:
        org_score = sfx_org_r * 0.30
    org_score = min(org_score, 0.98)

    # --- POI ---
    if f["poi_d4"] is None:
        poi_score = 0.0
    else:
        loc_r = f["poi_sfx_aff"].loc_ratio if f["poi_sfx_aff"] else 0.2
        has_poi_hint = any(f["poi_d4"].endswith(s) for s in POI_FACILITY_SUFFIXES)
        poi_score = loc_r * 0.75 + 0.15 * has_poi_hint
        poi_score = min(poi_score, 0.90)

    # --- ADDR --- [修正点 2]
    # addr_affinity 的 loc_ratio 因短地址前缀在 org 语料高频而偏低
    # （"深圳市" loc_ratio=0.00），不能作为基础分。
    # 改为 geo_cov 驱动，addr_aff 仅作 boost。
    addr_score = f["geo_cov"] * 0.50  # 基础分：loc 覆盖率高就高分
    if f["addr_aff"] and f["addr_aff"].loc_ratio > 0.5:
        addr_score += f["geo_cov"] * 0.25  # boost: addr_aff 确认 loc 主导
    if (f["has_comp"] or f["has_gov"]) or org_score > 0.45:
        addr_score *= 0.25  # ORG 压制
    addr_score = min(addr_score, 1.0)

    return {"ORG": org_score, "POI": poi_score, "ADDR": addr_score}
```

#### _decide（双硬规则 + 双负推断 + argmax）

```python
def _decide(self, f, scores):
    # 规则 1: 公司/政府后缀在末位 → ORG
    if (f["has_comp"] or f["has_gov"]) and f["org_has_poi_terminal"]:
        return "ORG", scores["ORG"]

    d4 = f.get("d4_suffix")
    if d4:
        # 规则 2a: 设施类后缀 → POI（免检）
        if any(d4.endswith(s) for s in POI_FACILITY_SUFFIXES):
            return "POI", max(scores["POI"], 0.75)

        # 规则 2b: 店铺类后缀
        if any(d4.endswith(s) for s in POI_STORE_SUFFIXES):
            # Signal 1: loc_result 有地理段 → POI
            if f["has_geo"]:
                return "POI", max(scores["POI"], 0.75)
            # Signal 2: 双负推断——d4∉suffix_csv 且 prefix∉trade_csv → 推定地名+店 → POI
            from core.csv_index import CsvIndex
            idx = CsvIndex.instance()
            store_sfx = max((s for s in POI_STORE_SUFFIXES if d4.endswith(s)), key=len)
            prefix = d4[:-len(store_sfx)] if len(d4) > len(store_sfx) else ""
            if prefix and d4 not in idx.suffix and prefix not in idx.trade:
                return "POI", max(scores["POI"], 0.70)

    # 规则 3: argmax
    best_cat = max(scores, key=scores.get)
    best_val = scores[best_cat]
    if best_val < self.T_UNKNOWN:
        return "UNKNOWN", best_val
    return best_cat, best_val
```

#### _select_best

```python
def _select_best(self, category, loc_res, org_res, poi_res):
    if category == "ORG":
        d = org_res.to_dict()
        for s in d["segments"]:
            s["type"] = _ORG_TYPE_REMAP.get(s["type"], s["type"])
        return d
    elif category == "POI":
        return poi_res.to_dict() if poi_res else None
    elif category == "ADDR":
        return loc_res.to_dict()
    return None
```

6. **gov seed 注入用 `max` 而非 `not in`**——已有但低频的 gov 后缀 (freq 726~37716) 必须提升到 50000。
7. **addr_score 以 geo_cov 为基础分**，addr_affinity 的 loc_ratio 因短地址前缀在 org 语料高频而偏低，仅作 boost，不能当基础分。
8. **T_UNKNOWN 是唯一待标定值**，通过 `__init__` 的 `t_unknown` 参数暴露。0.90/0.80/0.75/0.70/0.50/0.15/0.25/0.98 是评分档位结构常数，不要乱调。
9. **如果某用例不过**：先报告，不要为过测试而硬改公式。可能是 gov seed 缺词或 loc 词典覆盖问题。
10. **GBK 解码**：Gaode/Tencent 原始数据均为 GBK 编码，`errors="replace"`。
11. **双负推断用精确匹配**：`prefix not in idx.trade` 是精确查找（不 contains），避免"国贸"误匹配"国际贸易"。
12. **POI 后缀检查用 `endswith`**：`store_sfx = max((s for s in POI_STORE_SUFFIXES if d4.endswith(s)), key=len)` 取最长匹配。
