# dict_ner v3.0 系统性重构方案

> 主会话五代 | 编写: 2026-08-03
> 当前版本: v2.2.1 | 目标: v3.0 | 基线词典: v1.2.3
> 决策: 标签噪声程序清洗(不人工) / 允许第三方库 / 一次性重写

---

## 零、诊断（为什么 v2.x 强不了多少）

1. **补丁链架构**: v2.0→v2.2.1 全是 bolt-on 补丁(_remap/_merge_over_split/_detect_compound/_double_negative/查表调score), `_score`/`_decide` 堆 ~20 个手调魔法数, 无学习过程, 互相打架。
2. **打分体系崩溃** (v2.2.1, 180K): ADDR→UNKNOWN 25,846 (43%), POI→ORG 26,410 (最大错误格), UNKNOWN precision=0.0012。argmax+0.10阈值不是概率, 三类score量纲不同(ADDR上限0.75/ORG上限0.98)。
3. **评测标签有噪**: Gaode/Tencent type 机械映射(商务住宅→ADDR/公司企业含分支), 用有噪标签调手规则, 天花板0.37。
4. **三体系重复建设**: loc/org/poi 各自统计+剪枝+手工注入(gov seed/POI_EXCLUDE/split_polluted_d4), 打地鼠; brand 模型休眠。

## 一、核心转向

| 维度 | v2.2.1 | v3.0 |
|------|------|------|
| 分类决策 | 规则链+魔法数 | GBDT学习权重 + isotonic概率校准 |
| 训练数据 | 无 | 300万+弱标注(Gaode/Tencent全量采样) |
| 标签噪声 | 无处理 | Confident learning (5-fold CV矛盾剔除) |
| 置信度 | 伪分数 | 校准真概率 |
| 识别引擎 | 三套近重复DP | 一个引擎+三套参数化配置 |
| 评测 | 单指标无分层 | train/val/test固定切分+双指标+错误仪表盘 |

## 二、目标架构

```
v3/
├── engine/dp.py + configs.py   # 统一Viterbi DP引擎, LOC/ORG/POI三套配置 (P3)
├── features.py                 # ~45维特征: 段级/查表/统计/规则信号
├── labels.py                   # confident learning 标签清洗 (P2)
├── train.py                    # 训练: GBDT+校准+阈值标定+manifest (P1)
├── infer.py                    # 推理: classify/recognize 批量并行
├── evaluate.py                 # 评测: 混淆矩阵+per-class F1+错误样例仪表盘
└── pipeline.py                 # 新总线 (对外契约兼容 run.py)
models/                         # clf pkl + calibrator + manifest.json
```

## 三、数据流

```
Gaode 6450万 + Tencent 7200万 → 分层采样300万(种子42, 剔ATM/公交编号)
  → 特征预计算(16进程并行) → 45维特征+弱标签
  → labels.py 5-fold CV confident learning 清洗(剔10~20%)+映射级噪声率报告
  → train.py HistGradientBoosting + isotonic校准 + val集标定各类阈值
  → models/clf_v3.0.pkl + manifest.json
```

## 四、评测体系

1. eval_set 180K → train 60% / val 20% / test 20%, label×source 分层, 种子42, 持久化 data/eval_split_*.csv
2. 双指标: 原始标签 macro-F1(与历史可比) + 清洗标签 macro-F1(近似上限)
3. 错误仪表盘: 每混淆格 top-50 样例 → output/v3_error_report.md
4. 回归门禁: 统一DP引擎段文本差异 vs v2.2.1 < 0.5% (P3)

## 五、阶段与验收

| 阶段 | 内容 | 验收 |
|------|------|------|
| P0 | 方案文档+features.py+eval split+并行预计算 | 特征矩阵产出 |
| P1 | GBDT+校准+阈值标定, run.py v3 classify | val macro-F1 ≥ 0.45 (baseline 0.3702) |
| P2 | 300万弱标注+confident learning | val macro-F1 ≥ 0.50 + 噪声率报告 |
| P3 | 统一DP引擎, 旧模块退役 | 三体系段差异<0.5%, tests适配全绿 |
| P4 | 错误仪表盘+文档 | test集最终报告(只跑一次) |

## 六、红线与治理

1. v2.2.1 全部代码与词典冻结保留, run.py 默认入口在 v3 达标前不切换
2. 模型产物必带 manifest (数据hash+特征版本+参数+val指标)
3. 段识别改动过段差异门禁; 分类改动 val macro-F1 不降
4. 硬规则(公司/政府后缀末位→ORG)降级为特征+可选护栏, 由val实验决定
5. requirements.txt: scikit-learn, numpy, pandas (仅 v3/ 需要; 旧模块保持纯stdlib)

| macro-F1(原始标签) | 0.3702 | 0.50+ |
| ORG precision | 0.4371 | 0.70+ |

## 八、实施结果 (2026-08-04, 全部阶段完成)

| 阶段 | 结果 |
|------|------|
| P0 | 方案文档 + features.py (78维) + eval split (108,485/36,162/36,162) + 16进程预计算 |
| P1 | GBDT+isotonic+乘数标定, val macro-F1 0.7955 (验收≥0.45 ✓) |
| P2 | 270万弱标注 (Gaode 2M+Tencent 1M, 防泄漏), confident learning 3-fold 剔除 145,990 (5.4%), 重训 val macro-F1 0.8219 (验收≥0.50 ✓) |
| P3 | 统一 DP 引擎 v3/engine/, 20K 样本三体系零差异 (门禁<0.5% ✓), V3Pipeline 接入 features/infer |
| P4 | 错误仪表盘 output/v3_error_report.md + test 一次性报告 output/v3_test_report.md + README/HANDOVER 更新 |

**test 集 (36K, 一次性)**: macro-F1 0.7699, accuracy 0.9114 (v2.2.1: 0.3702 / 0.4463)。
**测试**: 124 条全绿 (112 legacy + 12 v3)。
**已知边界**: "星巴克咖啡望京店" → ADDR (0.51/0.48 微弱差距, 评测集中"望京"多标 ADDR)。
**技术债**: sklearn 1.9 需 FrozenEstimator 做 prefit 校准; UNKNOWN 类 support 极小 (val 10/test 9), 阈值类指标波动大。
