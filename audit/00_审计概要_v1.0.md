## 1. 项目概况

`dict_ner` 是一个从非结构化中文文本中识别地名/机构名/POI/品牌名的系统。四个模组基于同一 Viterbi DP 引擎，各有独立词典。

| 维度 | 数值 |
|------|------|
| 总代码行数 | ~3,400 行 Python |
| 源文件数 | 25 个 .py 文件 |
| 模块数 | core, loc, org, poi, brand, geomodel, tools (7个) + 根目录脚本 |
| 词典大小 | ~40MB (4个 .pkl) |
| 全量数据 | ~18GB |
| 识别速度 | ~15K rec/s (单核) |
| Python 版本 | 3.10+ |
| 第三方依赖 | 无 (纯标准库) |
