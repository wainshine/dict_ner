- `data/split/loc/chunk_XX.csv` — `dict,idf` 逗号分隔，总 ~3635 万行

### 三个 SQL CSV（基础数据，时间验证）

列结构：`d1/d3/d4,icf1,idf1,tf1,max1,com,org,loc,temp`（首行有 BOM）

com/org/loc 是**用 SQL 对 split/{loc,org,poi} 三套语料交叉统计段频**的结果，非来源于高德/腾讯 type 字段。`org_ratio>0.6` = 该段在机构名语料中出现频率高。

| CSV | 行数 | 统计 | 当前代码使用 |
|-----|-----:|------|------------|
| `addr_segments_sql.csv` | 200 万 | 37% org 主, 23% loc 主, 1.5% com 主, 38% 混合 | 仅 org d111 注入 |
| `trade_segments_sql.csv` | 4 万 | 62.6% org 主, 36.7% com 主 | **完全未使用（死数据）** |
| `suffix_segments_sql.csv` | 2.4 万 | 84.6% org 主, 14.8% loc 主 | 仅 org_aggregate 质量过滤 |

addr CSV 的 com/org/loc 统计特性：短地址前缀（"深圳市""北京市"）在 org 语料中极常见（大量"深圳市XX公司"），导致 org/com 远高于 loc。

| 深圳市 | 3.44M | 230K | 7.7K | 0.00 |
| 北京市朝阳区 | 891 | 7.8K | 7.8K | 0.47 |

因此 addr_affinity 的 loc_ratio 不能作为 addr_score 基础分，仅作 boost。

## 一、概念定义（最高优先级）

### 分类体系：4 类

| 类别 | 定义 | 判别特征 |
|------|------|---------|
| **ADDR** | 行政区划及组合、山川河流等自然地理、道路交通、街道小区门牌、方位词 | LOC 识别器全部输出范围 |
| **ORG** | 有组织机构代码的法人实体（公司/政府/事业单位/医院/学校/银行总部） | 公司后缀(公司/有限/集团)、政府后缀(委/局/办)、d4_category_map 标注为 ORG |
| **POI** | 连锁分支机构/店铺/服务点/公共设施——有地理属性的点位 | d4_category_map 标注为 POI_FAC(免检) 或 POI_STORE(需地理信号) |
| **UNKNOWN** | 无法判断 | 评分低于阈值 T |

### ORG vs POI 分界

- "华为技术有限公司" → ORG（公司法人）
- "广东省卫健委" → ORG（政府机构）
- "XX人民医院" → ORG（事业单位，无店铺后缀）
- "星巴克咖啡望京店" → POI（连锁分支 + 地理属性）
- "XX停车场" → POI（公共设施，免检）
- "理发店" → ORG（行业词 + 店，无地理属性）
- "北京市朝阳区" → ADDR
- "西湖" → ADDR

### 数据驱动原则

- **SQL CSV 是基础**：addr/trade/suffix 三表是手工 SQL 切分 + 时间验证的高质量数据
- **Gaode/Tencent 用来验证和标注**：不替代 SQL CSV，在其基础上增加 type 维度
- **手工后缀列表完全移除**：由 `d4_category_map.pkl` + `suffix_category_gaode.csv` 替代

### 0.1. `scripts/build_gaode_index.py`（新增）

**单脚本单次扫描 Gaode 67 文件**，同时产出三个数据文件。GBK 解码 `errors="replace"`，`csv.field_size_limit(2**20)`。

**核心逻辑**：

```
单次扫描 67 文件:
  对每行:
    1. 提取 name, type(1级/2级/3级), address
    2. 后缀统计: name 末尾 2/3/4 字 → suffix_type_freq[sfx][t1] += 1
    3. d4 标注: 检查 name 是否以某个 org d4 后缀结尾 → d4_type_dist[sfx][t1] += 1
    4. 道路名提取: 从 address 用正则提取 XX路/XX街/XX道 等 → road_freq[road] += 1
    5. 自然地名: type=地名地址信息;自然地名 → natural_names[name] += 1
    6. ATM 检测: type 含自动提款机 → atm_names 记录
```

### 1.2. `tools/org_aggregate.py` 改造

**版本升级** v1.1.2 → v1.2.1。改 `core/config.py` 的 `VERSION = "v1.2.1"`。

在 `main()` 中 `pruned = prune(merged, quality)` 之后、`pickle.dump` 之前插入 gov seed 注入：

```python
GOV_SEED = os.path.join(DATA_DIR, "gov_suffix_seed.csv")
GOV_SEED_FREQ = 50000


def merge_gov_seed(pruned):
    if not os.path.exists(GOV_SEED):
        return pruned, 0, 0
    d4 = dict(pruned["d4_freqs"])
    injected = 0
    boosted = 0
    with open(GOV_SEED, encoding="utf-8-sig") as f:
        for row in csv_mod.DictReader(f):
            sfx = row["suffix"].strip()
            if not sfx or len(sfx) < 2:
                continue
            old_freq = d4.get(sfx, 0)
            new_freq = max(old_freq, GOV_SEED_FREQ)
            if old_freq == 0:
                injected += 1
            elif new_freq > old_freq:
                boosted += 1
            d4[sfx] = new_freq
    pruned["d4_freqs"] = d4
    return pruned, injected, boosted


pruned, gov_injected, gov_boosted = merge_gov_seed(pruned)
print(f"Gov suffix seed: +{gov_injected} new, boosted {gov_boosted} existing "
      f"(total d4: {len(pruned['d4_freqs']):,})", flush=True)
```

关键：用 `max(d4.get(sfx, 0), GOV_SEED_FREQ)` 而非 `not in d4`——13 个已有但低频的 gov 后缀（freq 726~37716）必须提升到 50000。

### 1.3. `tools/merge_gaode_roads.py`（新增）

将 Gaode 道路名合并进 LOC 词典，输出 `loc_v1.2.1.pkl`。

```python
#!/usr/bin/env python3
"""合并 Gaode 道路名到 LOC 词典 → loc_v1.2.1.pkl"""
import os, sys, pickle, csv

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
from core.types import SegType

BASE = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
DICT_DIR = os.path.join(BASE, "dicts")
ROADS_CSV = os.path.join(BASE, "data", "gaode_roads.csv")


def main():
    src = os.path.join(DICT_DIR, "loc_v1.1.2.pkl")
    dst = os.path.join(DICT_DIR, "loc_v1.2.1.pkl")

    with open(src, "rb") as f:
        data = pickle.load(f)

    road_dict = data.get(SegType.ROAD, {})
    all_words = set()
    for seg_type, words in data.items():
        all_words.update(words.keys())

    added = 0
    skipped_existing = 0
    with open(ROADS_CSV, encoding="utf-8-sig") as f:
        for row in csv.DictReader(f):
            road = row["road_name"].strip()
            if not road or len(road) < 2:
                continue
            if road in road_dict:
                skipped_existing += 1
                continue
            if road in all_words:
                skipped_existing += 1
                continue
            road_dict[road] = max(50, int(row.get("freq", 3)))
            added += 1

    data[SegType.ROAD] = road_dict
    with open(dst, "wb") as f:
        pickle.dump(data, f)

    print(f"Merge complete: +{added} roads, {skipped_existing} already existed")
    print(f"Saved: {dst} ({os.path.getsize(dst) / 1024 / 1024:.1f}MB)")
    print(f"ROAD entries: {len(road_dict):,}")


if __name__ == "__main__":
    main()
```

### 2.1. `core/csv_index.py`（新增）

```python
"""CSV 亲和度索引 — 从手工切分的 SQL CSV 构建运行时评分信号

com/org/loc 列是用 SQL 对 split/{loc,org,poi} 三套语料交叉统计段频的结果。
SQL CSV 是基础数据，Gaode/Tencent 用来验证和标注，不替代 SQL CSV。
"""
import csv, os
from typing import Optional

BASE_DIR = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
DATA_DIR = os.path.join(BASE_DIR, "data")

SAFE_SINGLE = {"厂", "店", "站", "园", "局", "院"}


class AffinityEntry:
    __slots__ = ("word", "org", "loc", "com", "org_ratio", "loc_ratio")

    def __init__(self, word, org, loc, com):
        self.word = word
        self.org = org
        self.loc = loc
        self.com = com
        total = org + loc + com
        self.org_ratio = org / total if total > 0 else 0.0
        self.loc_ratio = loc / total if total > 0 else 0.0


def _load_affinity_csv(path, key_col):
    result = {}
    if not os.path.exists(path):
        return result
    with open(path, encoding="utf-8-sig") as f:
        for row in csv.DictReader(f):
            word = row[key_col].strip()
            if not word or len(word) < 1:
                continue
            if len(word) == 1 and word not in SAFE_SINGLE:
                continue
            try:
                com = int(row.get("com", 0) or 0)
                org = int(row.get("org", 0) or 0)
                loc = int(row.get("loc", 0) or 0)
            except (ValueError, KeyError):
                continue
            if org == 0 and loc == 0 and com == 0:
                continue
            result[word] = AffinityEntry(word, org, loc, com)
    return result


class CsvIndex:
    _instance = None

    def __init__(self):
        self._suffix = None
        self._trade = None
        self._addr = None

    @classmethod
    def instance(cls):
        if cls._instance is None:
            cls._instance = cls()
        return cls._instance

    @property
    def suffix(self):
        if self._suffix is None:
            self._suffix = _load_affinity_csv(
                os.path.join(DATA_DIR, "suffix_segments_sql.csv"), "d4")
        return self._suffix

    @property
    def trade(self):
        if self._trade is None:
            self._trade = _load_affinity_csv(
                os.path.join(DATA_DIR, "trade_segments_sql.csv"), "d3")
        return self._trade

    @property
    def addr(self):
        if self._addr is None:
            a = _load_affinity_csv(
                os.path.join(DATA_DIR, "addr_segments_sql.csv"), "d1")
            self._addr = {w: e for w, e in a.items()
                          if e.org >= 2 * max(e.loc, e.com)
                          or e.loc >= 2 * max(e.org, e.com)}
        return self._addr

    def lookup_suffix(self, text):
        if not text or not self.suffix:
            return None
        for end in range(len(text), 0, -1):
            for start in range(0, end):
                w = text[start:end]
                if w in self.suffix:
                    return self.suffix[w]
        return None

    def lookup_trade(self, text):
        if not text or not self.trade:
            return None
        best = None
        for w, e in self.trade.items():
            if w in text and (best is None or len(w) > len(best.word)):
                best = e
        return best

    def lookup_addr(self, text):
        if not text or not self.addr:
            return None
        for end in range(len(text), 0, -1):
            w = text[:end]
            if w in self.addr:
                return self.addr[w]
        return None
```

```python
def classify(self, text: str) -> dict:
    text = text.strip()
    if not text:
        return {"text": "", "category": "UNKNOWN", "confidence": 1.0,
                "best": None, "all": None}
    loc_res = self.loc.recognize(text)
    org_res = self.org.recognize(text)
    has_comp = self._has_company_suffix(org_res)
    poi_res = None if has_comp else self.poi.recognize(text)
    feats = self._extract_features(text, loc_res, org_res, poi_res, has_comp)
    scores = self._score(feats)
    category, confidence = self._decide(feats, scores)
    best = self._select_best(category, loc_res, org_res, poi_res)
    return {
        "text": text,
        "category": category,
        "confidence": round(confidence, 4),
        "best": best,
        "all": {
            "loc": loc_res.to_dict(),
            "org": org_res.to_dict(),
            "poi": poi_res.to_dict() if poi_res else None,
        },
    }

def classify_batch(self, texts) -> list:
    return [self.classify(t) for t in texts]
```

```python
def _extract_features(self, text, loc_res, org_res, poi_res, has_comp):
    from core.csv_index import CsvIndex
    idx = CsvIndex.instance()

    org_segs = org_res.segments
    org_last = org_segs[-1] if org_segs else None
    d4_suffix = org_last.text if (org_last and org_last.seg_type == SegType.POI) else None
    has_gov = False
    if org_last and d4_suffix:
        has_gov = any(org_last.text.endswith(g) for g in GOV_SUFFIXES)
    has_industry = any(s.seg_type == SegType.INDUSTRY for s in org_segs)

    poi_segs = poi_res.segments if poi_res else []
    poi_last = poi_segs[-1] if poi_segs else None
    poi_d4 = poi_last.text if (poi_last and poi_last.seg_type == SegType.POI) else None

    n = max(1, len(text))
    admin_cov = sum(len(s.text) for s in loc_res.segments
                    if s.seg_type in _ADDR_TYPES) / n
    location_cov = sum(len(s.text) for s in loc_res.segments
                       if s.seg_type in (SegType.LOCATION, SegType.ORIENTATION)) / n
    geo_cov = admin_cov + location_cov

    d1_prefix = ""
    for s in loc_res.segments:
        if s.seg_type in _ADDR_TYPES:
            d1_prefix += s.text
        else:
            break
    d1_prefix = d1_prefix or None

    d3_text = "".join(s.text for s in org_segs
                      if s.seg_type == SegType.INDUSTRY) or None

    sfx_aff = idx.lookup_suffix(d4_suffix) if d4_suffix else None
    trd_aff = idx.lookup_trade(d3_text) if d3_text else None
    addr_aff = idx.lookup_addr(d1_prefix) if d1_prefix else None
    poi_sfx_aff = idx.lookup_suffix(poi_d4) if poi_d4 else None

    has_geo = any(s.seg_type in _GEO_SEG_TYPES for s in loc_res.segments)

    return {
        "n": n, "has_comp": has_comp, "has_gov": has_gov,
        "d4_suffix": d4_suffix, "d3_text": d3_text, "d1_prefix": d1_prefix,
        "poi_d4": poi_d4, "has_industry": has_industry, "has_geo": has_geo,
        "org_has_poi_terminal": org_last is not None and org_last.seg_type == SegType.POI,
        "poi_has_poi_terminal": poi_last is not None and poi_last.seg_type == SegType.POI,
        "admin_cov": admin_cov, "geo_cov": geo_cov,
        "sfx_aff": sfx_aff, "trd_aff": trd_aff,
        "addr_aff": addr_aff, "poi_sfx_aff": poi_sfx_aff,
```

#### _score

```python
def _score(self, f):
    sfx_org_r = f["sfx_aff"].org_ratio if f["sfx_aff"] else 0.0
    trd_org_r = f["trd_aff"].org_ratio if f["trd_aff"] else 0.0
    if f["has_comp"] or f["has_gov"]:
        org_score = 0.90 + 0.08 * (f["has_industry"] or trd_org_r > 0.5)
    elif sfx_org_r > 0.6:
        org_score = sfx_org_r * 0.80
    else:
        org_score = sfx_org_r * 0.30
    org_score = min(org_score, 0.98)

    if f["poi_d4"] is None:
        poi_score = 0.0
    else:
        loc_r = f["poi_sfx_aff"].loc_ratio if f["poi_sfx_aff"] else 0.2
        poi_score = loc_r * 0.75
        poi_score = min(poi_score, 0.90)

    addr_score = f["geo_cov"] * 0.50
    if f["addr_aff"] and f["addr_aff"].loc_ratio > 0.5:
        addr_score += f["geo_cov"] * 0.25
    if (f["has_comp"] or f["has_gov"]) or org_score > 0.45:
        addr_score *= 0.25
    addr_score = min(addr_score, 1.0)

    return {"ORG": org_score, "POI": poi_score, "ADDR": addr_score}
```

```python
def _lookup_d4_category(self, d4):

def _lookup_suffix_category(self, d4):
    if not d4 or not self.suffix_table:
        return None
    for end in range(len(d4), 1, -1):
        for start in range(0, end):

def _double_negative(self, d4, idx):
    if not d4 or len(d4) < 2:
        return False
    for slen in range(min(4, len(d4) - 1), 1, -1):
        sfx_candidate = d4[-slen:]
        prefix = d4[:-slen]
        if prefix and d4 not in idx.suffix and prefix not in idx.trade:
            return True
    return False
```

#### _decide（四层数据驱动判定）

```python
def _decide(self, f, scores):
    scores = dict(scores)
    from core.csv_index import CsvIndex
    idx = CsvIndex.instance()

    # 规则 1: 公司/政府后缀在末位 → ORG
    if (f["has_comp"] or f["has_gov"]) and f["org_has_poi_terminal"]:
        return "ORG", scores["ORG"]

    d4 = f.get("d4_suffix")
    if d4:
        # 规则 2: d4 精确查 d4_category_map
        cat = self._lookup_d4_category(d4)
        if cat == "POI_FAC":
            return "POI", max(scores["POI"], 0.75)
        elif cat == "POI_STORE":
            if f["has_geo"] or self._double_negative(d4, idx):
                return "POI", max(scores["POI"], 0.75)
        elif cat == "ORG":
            scores["ORG"] = min(max(scores["ORG"], 0.80), 0.98)
        # AMBIGUOUS/ADDR/UNKNOWN/None → 进入规则 3

        # 规则 3: endswith 查 suffix_category_gaode
        if cat in (None, "AMBIGUOUS", "UNKNOWN"):
            cat_sfx = self._lookup_suffix_category(d4)
            if cat_sfx == "POI_FAC":
                return "POI", max(scores["POI"], 0.75)
            elif cat_sfx == "POI_STORE":
                if f["has_geo"] or self._double_negative(d4, idx):
                    return "POI", max(scores["POI"], 0.75)
            elif cat_sfx == "ORG":
                scores["ORG"] = min(max(scores["ORG"], 0.80), 0.98)

    # 规则 4: argmax
    best_cat = max(scores, key=scores.get)
    best_val = scores[best_cat]
    if best_val < self.T_UNKNOWN:
        return "UNKNOWN", best_val
    return best_cat, best_val
```

```python
def _select_best(self, category, loc_res, org_res, poi_res):
    if category == "ORG":
        d = org_res.to_dict()
        for s in d["segments"]:
            s["type"] = _ORG_TYPE_REMAP.get(s["type"], s["type"])
        return d
    elif category == "POI":
        return poi_res.to_dict() if poi_res else None
    elif category == "ADDR":
        return loc_res.to_dict()
    return None
```

### 3.2. `tools/build_eval_set.py`（新增）

**格式**：

**采样逻辑**：

1. **Gaode 按全量 type 比例采样 10 万条**：

2. **Tencent 按比例采样 5 万条**：345 文件按文件大小加权 sampling，种子 42。GBK 解码。取 `name` 列（index 1）作 text，`category` 列（index 6）取分号前 1 级作 type_orig。按映射表转 label。剔除 type_orig ∈ {其它} 及纯数字/字母编号。剔除 text 为空/纯数字/长度>50。

### 3.3. `tools/eval_classify.py`（新增）

**调用**：
```bash
python tools/eval_classify.py                              # 默认 data/eval_set.csv
python tools/eval_classify.py --eval path/to/set.csv       # 指定评测集
python tools/eval_classify.py --baseline old_result.json   # 对比基线
python tools/eval_classify.py --out result.json            # 保存当前结果
```

**逻辑**：
1. 加载评测集 CSV
2. 实例化 `DictNerPipeline`，调 `pipe.classify_batch(texts)`
3. 对每条：`predicted = result["category"]`，`expected = label`
4. 统计：混淆矩阵 4×4（行=expected，列=predicted，顺序 ORG/POI/ADDR/UNKNOWN）、per-class precision/recall/F1、macro-F1、accuracy
5. `--baseline`：加载旧 JSON，并排打印每项 delta
6. `--out`：保存 JSON（含 timestamp、版本、混淆矩阵、per-class 指标）

### 3.4. v1.2.3 基线

用临时简易分类器（使用 v1.1.2 词典）：
```python
def _baseline_classify(pipe, text):
    org_res = pipe.org.recognize(text)
    if pipe._has_company_suffix(org_res):
        return "ORG"
    loc_res = pipe.loc.recognize(text)
    geo_cov = sum(len(s.text) for s in loc_res.segments
                  if s.seg_type in _GEO_SEG_TYPES) / max(1, len(text))
    if geo_cov > 0.6:
        return "ADDR"
    poi_res = pipe.poi.recognize(text)
    if poi_res.segments:
        return "POI"
    return "UNKNOWN"
```

保存 → `baseline_v1.2.3.json`。阶段 4 用正式 `classify()` 重跑替换。

## 十三、DeepSeek 实施守则

1. **不擅自扩大改动范围**：冻结红线里的文件一个字符都不改。如发现必须改，先停下报告。
2. **不新增 SegType，不改训练管道核心逻辑**。
3. **代码风格**：纯标准库、4 空格缩进、无第三方依赖、无 emoji。
4. **不加注释**（docstring 可保留给公开 API）。
5. **gov_suffix_seed.csv 必含"卫健委"**。
6. **gov seed 注入用 `max` 而非 `not in`**——已有但低频的 gov 后缀 (freq 726~37716) 必须提升到 50000。
7. **addr_score 以 geo_cov 为基础分**，addr_affinity 的 loc_ratio 仅作 boost。
8. **T_UNKNOWN 是唯一待标定值**，通过 `__init__` 的 `t_unknown` 参数暴露。
9. **手工 POI 后缀列表完全移除**——不定义 POI_FACILITY_SUFFIXES 和 POI_STORE_SUFFIXES，全部依赖 d4_category_map + suffix_category_gaode。
10. **SQL CSV 是基础，Gaode 用来验证**——suffix_category_gaode.csv 的 final_category 需交叉验证 SQL CSV。
11. **GBK 解码**：Gaode/Tencent 原始数据均为 GBK 编码，`errors="replace"`。
12. **csv.field_size_limit(2**20)**：3 个 Gaode 文件超默认限制。
13. **双负推断用精确匹配**：`prefix not in idx.trade` 是精确查找（不 contains）。
14. **v1.1.2 词典全部保留**，不覆盖。新词典版本 v1.2.1。
15. **如果某用例不过**：先报告，不要为过测试而硬改公式。
16. **build_gaode_index.py 单次扫描**：67 文件只读一遍，同时产出 3 个文件。
